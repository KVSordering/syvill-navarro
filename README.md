# Syvill Navarro — Digital Business Card

A premium interactive personal website that functions as a digital business card.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion

## Getting Started

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
```

Deploy the `dist/` folder to [Vercel](https://vercel.com), [Railway](https://railway.app), or any static host.

### Vercel (recommended)

1. Push this repo to GitHub
2. Import the project in Vercel
3. Framework preset: **Vite**
4. Deploy

## Customization

Update contact links in `src/components/Contact.jsx`.

Replace mock screenshots in `public/images/work/` with your own project images.
